# 示例：一个真实的三层档案（脱敏后）

这是把本项目用在真实环境里的样子，全部内容已脱敏。

目录结构：

```
~/.dsh/
└── AGENTS.md                 ← 核心层，每轮自动注入（约 22KB）
project/
├── AGENTS.md                 ← 项目层，同样自动注入（约 2KB）
└── 记忆/                      ← 路由层，不自动加载（11 个文件，约 110KB）
    ├── README.md
    ├── 设备与网络.md
    ├── 常驻项目.md
    ├── 技术决策与结论.md

    ├── CF-Workers与API通道.md
    ├── 毕设与账号.md
    ├── AWS-Guidance.md
```

## 核心层的关键片段

### 1. 硬规则 + 关键词路由表

````markdown
### 检索与记忆硬规则（**每次回答前自检，不是建议**）

**四问自检**（任一为「是」→ 先 read / 走流程再动）：
1. 用户话里出现下表关键词？——**字面匹配即命中**，不因「感觉不相关」跳过。
2. 要改配置/文件/系统状态？——先 read `记忆\README.md`。
3. 这是排障？——先 read `记忆\经验教训.md`。
4. 要新增/修改记忆？——加载 `memory-intake` skill 按流程走。

| 命中关键词（任一） | 必须 read |
|---|---|
| `FlClash` `TUN` `4088` `198.18` `代理` `节点` `DNS` `域名` `证书` | `记忆\节点与代理.md` |
| `插件` `cordis` `升级` `启动脚本` `pnpm` | `记忆\DSH-插件与存储.md` |
| `反代` `provider` `APIKey` `凭据` `CF` `Workers` `测速` | `记忆\CF-Workers与API通道.md` |
| `报错` `失败` `不生效` `乱码` `超时` `400` `403` | `记忆\经验教训.md` |
| `记忆` `档案` `AGENTS.md` `预算` `注入` | `记忆\README.md` |

**违反代价**：不 read 就动手 = 重复踩过的坑，历史代价从数小时到数据丢失不等。
````

### 2. 常错清单（压缩到一句话的操作纪律）

````markdown
## 六、常错清单（高频踩坑·**每轮都要看**）

- 写给自己跑的 `.ps1` **绝不能有中文**，除非存 UTF-8 带 BOM：PS 5.1 按 GBK 解
  → 乱码吃掉引号 → 报假语法错。
- **读凭据只取键名、绝不打印值**（曾有一条调试正则把 8 个 token 打进了会话）。
- **换 API 上游必须同步 4 项**（`baseURL`、模型 ID、`maxTokensField`、
  `supportsReasoningEffort`），少一项即 400；换上游就开新会话。
- 会话权威存储是分片 `…\sessions\session-<id>.json`，聚合 json 没人读。
````

### 3. 新增记忆的流程（写进核心层的第七节）

````markdown
**维护纪律 · 新增记忆四步流程（不许跳步）**

1. **先判是否常驻**——三问任一为「是」→ 常驻：
   - 每轮都要遵守？（偏好、铁律、默认行为）
   - 做错就出大事？（安全 / 资金 / 数据 / 密钥 / 不可逆）
   - 每次都要用的关键标识符？（命令、字段、路径、版本、端口、金额）
2. **是 → 进本档**：单行 · 结论式 · ≤90 字 · 保留反引号技术串；插小节中前部。
3. **否 → 进外置库**：写 `记忆\` 对应文件；本档已有指针就不动，没有就加一行。
4. **⭐ 再补硬提示词（最容易漏）**：
   - 新关键词 → 必须加进第二节关键词表
   - 新 `.md` 文件 → 必须同时更新三处（本档索引 + 库 README + 关键词表）
5. **收尾核字节**：本档 ≤ 50KB（预算 65536 = 全局 + 项目 + CLAUDE.md 合计）。
````

## 为什么这样分

| 内容 | 层 | 理由 |
|---|---|---|
| 「读凭据只取键名」 | 核心 | 每轮都可能碰到，做错直接泄露 |
| 「某个项目的网格布局实现」 | 路由 | 一年用不上一次，进了核心就是纯烧 token |
| 「`65229` 是硬上限」 | **删掉** | 已被 `65536` 推翻，留着会让模型按错的算 |

## 一次真实体检结果

```
=== memory-doctor ===

✓ bytes     24096 / 65536 (core 22128 + project 1968 + CLAUDE.md 0), headroom 41440
✓ stale     none
✓ sections  contiguous, no duplicates
✓ pointers  11/11 resolve

```

`reverse` 这一项是重点：它抓的是「文件存在但没有任何东西指向它」——也就是
「写了但永远读不到」这个本项目的核心失败模式。
